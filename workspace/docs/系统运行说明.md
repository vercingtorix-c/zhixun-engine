## 1. 环境要求

- Python ≥ 3.10（开发验证：3.13）
- 依赖：`numpy`、`scikit-learn`（其余为标准库，无外网依赖）
- 可选：GPU 非必需；系统在 CPU 上即可跑通（赛题"有 GPU 即可"为充分不必要条件）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy scikit-learn
```

## 2. 数据集准备

| 数据集 | 放置位置 | 说明 |
|---|---|---|
| 内置仿真流 | 无需 | `--dataset synthetic`，离线可跑，含 5 类漂移 + 空跑包 |
| UCI Gas | `data/raw/*.zip` | 下载 https://archive.ics.uci.edu/dataset/224/gas 后把 zip 放入 |
| CMAPSS | `data/raw/cmapss/train_FD00*.txt` | 从 data.gov 下载 FD001/FD002/FD004 |
| XJTU-SY | `data/raw/xjtu-sy/**/*.csv` | 按官方 README 下载后放入 |

## 3. 运行

```powershell
# 基础运行（内置仿真流，闭环含数字孪生预演 + 无预演对照 + 静态基线 + 定期重训）
.\.venv\Scripts\python.exe run.py --dataset synthetic --out runs/synthetic

# 只跑本方案（跳过对照，最快）
.\.venv\Scripts\python.exe run.py --dataset synthetic --no-baselines

# 额外加入"无差别全量重调参"成本对照
.\.venv\Scripts\python.exe run.py --dataset synthetic --full

# 关闭数字孪生预演
.\.venv\Scripts\python.exe run.py --dataset synthetic --no-sim

# 真实数据
.\.venv\Scripts\python.exe run.py --dataset gas --out runs/gas
.\.venv\Scripts\python.exe run.py --dataset cmapss --out runs/cmapss

# 官方数据包续训闭环（A 气体识别 / B 轴承寿命 / C 发动机寿命）
.\.venv\Scripts\python.exe run.py --dataset official-a --windows 5 --out runs/official-a
.\.venv\Scripts\python.exe run.py --dataset official-b --windows 9 --out runs/official-b
.\.venv\Scripts\python.exe run.py --dataset official-c --windows 12 --out runs/official-c

# 导出 SwanLab 兼容云端记录（提交物②）
.\.venv\Scripts\python.exe tools\export_swanlab.py runs\official-b
```

## 4. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--dataset` | synthetic | synthetic / gas / cmapss / xjtu / official-a / official-b / official-c |
| `--windows` | 12 | 数据窗数量（官方任务按单元切分，见 `engine/official/loader.py`） |
| `--seed` | 42 | 固定后全流程可复现 |
| `--out` | runs/时间戳 | 输出目录 |
| `--official-dir` | ../official-data | 官方数据包根目录（A-gas / B-bearing / C-engine） |
| `--full` | 关 | 追加最贵的无差别重调参对照 |
| `--no-sim` | 关 | 关闭数字孪生预演 |
| `--no-baselines` | 关 | 只跑本方案 |

## 5. 产物说明

```
runs/<run_id>/
├── dashboard.html                  # 答辩看板（自包含，离线可开）
├── report.md                       # 复盘报告
├── results.json                    # 结构化结果（含逐窗决策链）
├── closed_loop/
│   ├── trace.jsonl                 # 闭环（含预演）全轨迹实验记录
│   ├── version_chain.json          # 版本哈希链
│   ├── reproduce.md                # 复现指引
│   └── versions/v0001/…            # 封版：manifest.json + config.json + model.pkl
└── closed_loop_nosim/…             # 无预演对照的同构产物
```

`trace.jsonl` 是完整实验轨迹，关键事件类型（答辩可逐条展示）：

| 事件 | 含义 |
|---|---|
| `monitor/drift-check` | 漂移监测，含 `trend`（趋势）、`eta_windows`（预计超阈值步数）、`feature_direction`（逐特征方向语义） |
| `diagnose/strategy` | 诊断归因，含 `attributions`（特征贡献 + 方向）、`pre-drift`（前瞻预警动作） |
| `incident/assess` | 故障分级 + 优先级评分（安全/系统/数据质量/性能） |
| `simulator/preplay` / `freeze-on-drift` | 数字孪生预演 / 检出漂移时冻结仿真 |
| `gate/sim-robustness` | 候选在合成"未来工况"上的抗漂移稳健性门槛 |
| `safety/refusal` | 安全拒绝机制（输入越界/低置信/输出越界） |
| `budget/adaptive` | 成本收益自适应预算缩放 |
| `seal` / `gate/promote` / `gate/rollback` | 封版 / 晋升 / 回滚 |

SwanLab 导出（提交物②）：`tools\export_swanlab.py <run_dir>` 会生成
`swanlab_export/config.json`、`metrics.jsonl`、`replay.py`；装了 swanlab 后运行
`replay.py` 即可把本地逐窗指标回放到云端，与本地 trace 同源。

## 7. 决策隔离（重要）

系统**只在在线可得的有标签训练数据**上做监测/诊断/优化/上线判断；
每个窗口的 `X_eval / y_eval`（模拟隐藏测试集）只由外部裁判用于事后打分，
**不参与任何训练或上线决策**。这保证：换成官方隐藏测试集时，行为一致、无泄漏。
