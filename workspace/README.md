# 智训引擎（DriftForge）

第二届北京市大学生「人工智能+」创新大赛 · 赛题一《智训引擎：工业制造场景下的模型训练与超参数优化》（软通计算机 × 华为命题）

> 核心命题：让工业模型在**漂移数据流**上实现**无人干预、自我进化**。

本仓库是一个可运行、可复现、可答辩的最小闭环系统，内置一条工业仿真漂移流，
并已接入三类真实工业数据（UCI Gas 传感器漂移 / NASA CMAPSS / XJTU-SY 轴承）。

## 一、系统做了什么

在赛题要求的五步闭环之上，融合了多个可落地的创新点：

```
         ┌──────────────────────── 无漂移（空闲算力） ────────────────────────┐
         │  数字孪生预演：代理模型 f(x) + 漂移算子库，主动合成未来工况           │
         │  生成虚拟样本 → 预适应缓冲 → 模型被"预免疫"                          │
         └────────────────────────────────────────────────────────────────────┘
         ┌──────────────────────── 检出漂移（算力全部转投） ────────────────────┐
         │  监测(PSI/KS/误差抬升) → 诊断归因(协变量/概念/复合) → 实验优化        │
         │  (逐次减半+预算+白名单) → 评估上线(增益/稳定/抗干扰/成本/安全)        │
         │  → 通过则晋升+封版 / 未通过则回滚到上一稳定版本                       │
         └────────────────────────────────────────────────────────────────────┘
```

- **被动响应**：漂移发生后，五步闭环自动"漂移监测—诊断归因—实验优化—评估上线—回滚"；
  候选模型过门槛才晋升上线并封版，否则显式回滚，保持上一稳定版本在线。
- **两层自进化**：模型层自迭代（重训/重调参更新模型参数）+ 策略层自改进
  （诊断策略、故障优先级评分、仿真开关与预算分配随反馈自适应调整）。
- **主动预演**：漂移未发生时，用当前工况学到的代理模型按漂移算子库合成"可能发生的未来"，先丰富数据库、预免疫模型；一旦真实漂移出现，立即冻结仿真、算力全部转投优化。
- **故障分级 + 优先级评分**：多突发并发时，把信号归入安全/系统/数据质量/性能四类，按"类别基础分×严重度×强度"评分，安全故障无条件置顶，先处理会伤人的、再处理资源的、最后才优化性能。
- **可解释根因归因**：逐特征输出方向语义（均值上移/方差增大/方差坍缩…）+ 误差贡献变化，得到"哪个传感器、往哪漂、影响多大"的证据链。
- **漂移前瞻预警**：趋势外推，当前未超阈值但斜率向上时提前低成本防御（`pre-drift`），缩短恢复步数。
- **安全拒绝机制**：输入越界 / 置信度不足 / 输出越界三重拒答，留痕可审计（赛题安全合规硬要求）。
- **成本收益自适应预算**：算力投入与漂移严重度、恢复难度、剩余预算挂钩，花最少的钱换最大的增益。

## 二、目录结构

```
zhixun-engine/
├── run.py                 # 一键运行入口
├── engine/
│   ├── types.py           # 统一数据契约（回归/分类、评分口径）
│   ├── streams.py         # 仿真流 + gas/cmapss/xjtu 适配器
│   ├── model.py           # 模型族、搜索空间、白名单校验、安全兜底
│   ├── monitor.py         # 第1步 漂移监测（PSI/KS/误差/空跑包识别）
│   ├── diagnose.py        # 第2步 诊断归因（协变量/概念/复合 + 特征归因）
│   ├── incident.py        # 故障分级与优先级评分（安全/系统/数据质量/性能）
│   ├── safety.py          # 安全拒绝机制（输入越界/低置信/输出越界三重拒答）
│   ├── optimizer.py       # 第3步 实验优化（逐次减半 + 预算 + 白名单）
│   ├── gate.py            # 第4步 评估上线（增益/稳定/抗干扰/延迟/安全）
│   ├── seal.py            # 第5步 回滚/封版（不可变快照 + 哈希链 + 复现清单）
│   ├── simulator.py       # 数字孪生仿真场（漂移算子库 + 主动预演）
│   ├── loop.py            # 五步闭环编排器 + 对照策略
│   ├── official/          # 官方 NumPy MLP 续训闭环（A/B/C 三任务适配）
│   ├── metrics.py         # 恢复速度/稳定性/抗干扰等赛题指标
│   ├── trace.py           # 全轨迹实验记录（JSONL）
│   └── report.py          # 自包含 HTML 看板 + Markdown 复盘
├── tools/
│   └── export_swanlab.py  # 导出 SwanLab 兼容云端记录（提交物②）
├── docs/
│   ├── 系统运行说明.md
│   └── 方案设计与答辩要点.md
├── data/raw/              # 数据集（不提交，仅本地复现用）
└── runs/                  # 每次运行的产物（看板/报告/轨迹/封版）
```

## 三、快速开始

```powershell
# 建独立环境（一次性）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy scikit-learn

# 跑内置仿真流（离线可跑，无需任何数据集）
.\.venv\Scripts\python.exe run.py --dataset synthetic --out runs/synthetic

# 跑真实传感器漂移数据（先把 gas zip 放到 data/raw/）
.\.venv\Scripts\python.exe run.py --dataset gas --out runs/gas

# 跑 CMAPSS（把 train_FD00*.txt 放到 data/raw/cmapss/）
.\.venv\Scripts\python.exe run.py --dataset cmapss --out runs/cmapss

# 跑官方数据包续训闭环（A 气体识别 / B 轴承寿命 / C 发动机寿命）
.\.venv\Scripts\python.exe run.py --dataset official-b --windows 9 --out runs/official-b
.\.venv\Scripts\python.exe run.py --dataset official-c --windows 12 --out runs/official-c

# 导出 SwanLab 兼容云端记录（提交物②）
.\.venv\Scripts\python.exe tools\export_swanlab.py runs\official-b
```

产物：`dashboard.html`（答辩看板，双击即开）、`report.md`、`results.json`、
`closed_loop/trace.jsonl`（全轨迹）、`closed_loop/versions/`（封版 + 哈希链）。

## 四、三条答辩硬门槛怎么满足

| 硬门槛 | 本系统如何满足 |
|---|---|
| 自主运行 | 评测窗标签不参与任何决策，闭环全自动，`--seed` 固定即完全复现 |
| 记录完整 | `trace.jsonl` 逐步留痕（配置/随机种子/预算/得分/耗时/决策理由） |
| 跑通基线 | 内置静态基线、定期重训、无差别重调参三条对照，同一口径可比 |

安全合规：模型配置走白名单校验、推理输出有 NaN/越界拒答兜底、无外网访问、
版本哈希链可审计，作品完全开源可验证。

## 五、官方评分口径与提交物（对齐《赛题规则》）

- **客观分**：由评测平台按步骤自动计算，核心是**单位增益消耗的算力
  （GPU 时长 / 训练额度）、标注配额与大模型 Token**——即"花最少的钱换最大的增益"。
  本系统的算力记账、逐次减半、预算封顶、白名单校验，正是为这一口径设计的。
- **主观分**：方法设计与技术路线、实验规范与分析深度、安全可控与工业落地、报告与答辩。
- **三份提交物**：① 模型配置与 Harness 系统镜像；② 完整的云端实验记录链接或查询依据
  （SwanLab）；③ 系统运行说明文档。
- **官方数据包**：训练集 + 验证集（含标签，公开发布）+ 评测脚本 + 隐藏测试流（不公开）。
  对接后只需替换 `engine/streams.py` 里的适配器，闭环本体不变。
