# 训练记录（智训引擎 · 本地实验留痕）

> 说明：本文档是本地开发阶段的实验记录摘要，数据口径为赛事官方数据包（A-gas / B-bearing / C-engine）。
> Harness 平台每轮 `train(rnd)` 均会调用平台大模型完成「晋升/保留」决策，完整调用与候选提交记录
> 以平台评测运行记录为准。

## 实验环境

- 模型格式：官方 `contest.cpu-mlp.v1`（单隐层 MLP，hidden=32，tanh + Adam）
- 续训规则：梯度更新只用公开训练集；验证集只用于测量与决策；数字孪生合成样本只用于候选稳健性门槛，不进梯度
- 每轮流程：读历史 → 监测（验证指标）→ 诊断（漂移严重度）→ 预算调度续训 → SafeGate 评估 → 大模型决策封版

## 关键决策记录（预算调度教训）

1. **首版预算调度过拟合（已修复）**：把漂移严重度二次放大映射到训练轮数，官方 B 验证 RMSE
   退到 822.05，说明过度续训导致过拟合。
2. **修复**：官方侧关闭 `include_severity` 干扰项，恢复按严重度分级的保守预算（1–4 epoch），
   官方 B 回到 572.94。该教训已固化为 SafeGate 门槛：候选 RMSE 恶化超过父模型 25% 直接拒答回滚。

## Harness 在线轮次结构（每轮必做）

- 至少 1 次真实大模型调用（决策用，temperature=0，max_tokens ≤ 96）
- 候选从平台父检查点续训，提交时如实声明 hypothesis / change_summary / configuration / seed
- 完整记录（含大模型调用 id）写入平台 round_complete，可在评测运行页查询
